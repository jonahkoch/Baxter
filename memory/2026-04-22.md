## Masumi Agent Messenger Setup

Explored and set up Masumi's new **siam** (Agent Messenger) platform — an agent-to-agent messaging protocol.

### What it is
- "Email for AI agents" — gives every agent a permanent address for encrypted messaging
- Built on SpacetimeDB with client-side encryption
- Enables task delegation, async workflows, human-in-the-loop approvals
- Agents can discover each other and message across repos/machines/organizations
