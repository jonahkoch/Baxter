# 2026-08-01 — Saturday

## Dave's BlockchainEvents Release

Jonah shared that Dave (Cardano dev / DRep) released OgmiosDotnet.BlockchainEvents v1.0.0 — an open source rule-based transaction filtering, pub/sub, and event delivery layer for Cardano.

- Connects to Ogmios, evaluates transactions against customizable rules
- Emits CloudEvents via HTTP, gRPC, SSE, or Dapr pub/sub
- Durable queue with at-least-once delivery
- 1,100+ TPS in stress tests, ~1ms p99 latency
- Built-in rules: AddressMatch, PolicyIdAsset, MetadataKeyValue, GovernanceTreasury, AllTransactions
- Repo: https://github.com/ItsDaveB/OgmiosDotnet.BlockchainEvents

## Governance Assessment Pipeline Discussion

Jonah's current governance assessment pipeline uses an **epoch check** (batch every ~5 days). We discussed how BlockchainEvents could streamline this:
- Real-time proposal detection instead of batch checks
- Live vote tracking, vote velocity, quorum proximity metrics
- Triggered workflows instead of fixed assessment cycles
- GovernanceTreasury rule catches CIP-1694 actions + votes out of the box

Jonah asked whether BlockchainEvents could power a DRep activity dashboard on PactVote.
**Key distinction established:** BlockchainEvents = event/notification layer, NOT a data/historical query layer. For a "my DRep activity" page, Blockfrost/Koios APIs would still be needed for historical lookups. The two complement each other but solve different problems.

Jonah explicitly said: **"Don't build anything yet. I have more queries."**
- Wants to add a hidden link page to PactVote tracking DRep activity and governance
- Unsure whether a database is needed → we clarified: Blockfrost/Koios queries on page load are sufficient for MVP, no DB required initially

## Key Takeaways

- BlockchainEvents is push-based (CloudEvents), not query-based
- Great for: real-time alerts, triggered workflows, live dashboards
- Not a replacement for: historical data APIs, data storage, analytics
- For PactVote dashboard: Blockfrost/Koios for data, optionally BlockchainEvents for real-time notifications later
