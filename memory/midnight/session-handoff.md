## What is Midnight?
Midnight is a **partner chain** to Cardano focused on **data protection and selective disclosure**. It enables:
- Privacy-preserving smart contracts
- Zero-knowledge proofs (ZKPs)
- Selective disclosure of private information
- Confidential DeFi and general-purpose smart contracts

## Key Concepts

### Core Architecture
- **Hybrid model**: Combines UTXO and account-based approaches
- **Kachina**: Data-protecting smart contract solution
- **Zswap**: Multi-asset support with atomic swaps (for DeFi)
- **Impact VM**: Midnight's execution environment

### Smart Contract Language
- **Compact**: Purpose-built language for Midnight
  - Strongly statically typed
  - Bounded execution guarantees
  - Compiles to zero-knowledge circuits
  - VS Code extension available
