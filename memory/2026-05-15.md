## Google Account Integration Request

Jonah asked about giving me access to a Google account (Gmail, Calendar, Drive) similar to how GitHub access works.

**Investigation results:**
- **Gmail**: Native support exists via OpenClaw hooks + Pub/Sub + `gog` (gogcli). Has a setup wizard: `openclaw webhooks gmail setup --account <email>`. Requires gcloud CLI, GCP project, Tailscale Funnel for HTTPS endpoint.
- **Google Calendar**: No native tool. Options: (1) browser automation via Chrome, (2) build a custom skill using Google Calendar API + OAuth.
- **Google Drive**: No native tool. Same options as Calendar.
- **Google Chat channel**: Has a plugin (`googlechat`) but that's for receiving messages via Google Chat, not for API access.

**Bundled plugins available** (from `openclaw plugins list`):
- `google-antigravity-auth` — for Google Cloud Code Assist (OAuth provider)
- `google-gemini-cli-auth` — for Gemini CLI auth
- `googlechat` — Google Chat channel plugin

None of these provide Gmail/Calendar/Drive API access directly.

**Recommended path**: Set up native Gmail first (built-in), use browser automation for Calendar/Drive as needed, build a Google skill later if heavy automation is required.
