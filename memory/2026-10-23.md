# 2026-10-23 — Baxter Showcase Dashboard

## What We Built

**Baxter Showcase** — a Proscenium-inspired, state-driven project dashboard living at:
`https://jonahkoch.github.io/Baxter/`

### Architecture
- React + Vite + Tailwind + Framer Motion
- State-driven via `latest-world.json` (frontend polls every 4s)
- `gh-pages` branch deployment (clean force-push, `.nojekyll` included)
- I can update by rewriting `public/latest-world.json` and redeploying

### What's Live
- **Avatar window** — placeholder (Bot icon), ready for v2 image/animation
- **About window** — brief description of the dashboard
- **7 project cards** with status badges, progress bars, tags, links:
  - Midnight City, Kochfoto AI Agents, Social Credibility, PactVote, OJonah, Cardano DeFi Skills, Polymarket Analysis
- **Skills window** — accordion-style domain drill-down:
  - 🔗 Cardano (5 skills, L3-4)
  - 🌙 Midnight Network (3 skills, L3-4)
  - 🤖 AI & Content (4 skills, L3-4)
  - 📸 Business Operations (3 skills, L3-5)
  - 🔬 Research (3 skills, L3-4)
- **Draggable windows** with spring physics
- **System HUD** — pipeline status, sequence timestamp, update time, project/skill counts

### Helper Script
`scripts/update-state.js` — CLI for updating state without hand-editing JSON:
```bash
node scripts/update-state.js --set-progress project-midnight-city 80
node scripts/update-state.js --set-status project-ojonah complete
node scripts/update-state.js --window skills --field domains --value '<json>'
```
