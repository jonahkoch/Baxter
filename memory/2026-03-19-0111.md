## Core Argument

**The Problem: Misspecified Feedback**
- Human feedback (RLHF, DPO, etc.) is systematically biased on certain inputs — like "a broken compass that points the wrong way in specific regions"
- These "problematic contexts" (X_hard) occur with probability α and have bias strength ε

**The Key Result (Murphy's Gap):**
Without knowing where feedback is unreliable, you need **exponentially many samples** — exp(n·α·ε²) — to distinguish between two reward functions that differ only on these edge cases.

**The Fix:**
With a "calibration oracle" that flags unreliable contexts, you can overcome this with just **O(1/(α·ε²)) queries** — a simple majority test on flagged contexts.

## Bottom Line
> *"Murphy's Law for AI alignment: the gap always wins unless you actively route around misspecification."*

The gap between what we optimize (proxy from human feedback) and what we want (true objective) is fundamentally limited by:
- How common the edge cases are (α)
- How wrong the feedback is there (ε)  
- How much the true objectives disagree (γ)
