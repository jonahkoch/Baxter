# Content Quality Gates

## Scoring Rubric

Rate every piece of content 1-5 on each dimension:

| Dimension | 1 (Poor) | 3 (Okay) | 5 (Excellent) |
|-----------|----------|----------|---------------|
| **Voice Match** | Sounds generic, could be any photographer | Mostly on-brand, few slips | Undeniably Kochfoto, unmistakably Jonah |
| **Hook Strength** | Boring opener, no reason to keep reading | Clear topic, mild interest | Stop-scrolling, must-know-what-happens |
| **Specificity** | Generic abstractions everywhere | Some details, some filler | Vivid, specific, you can picture it |
| **Value Density** | No takeaway, pure fluff | One useful idea | Multiple insights, worth saving/sharing |
| **Emotional Resonance** | Cold, transactional | Warm but forgettable | You feel something, you remember it |

**Minimum to pass:** 3.5 average, no dimension below 3
**Auto-revise if:** Voice Match < 3 or Hook Strength < 3

---

## Revision Rules

### If Voice Match < 3
- Replace corporate abstractions with specific details
- Add contractions
- Cut phrases like "timeless elegance" and "capturing memories"
- Rewrite in first person, active voice

### If Hook Strength < 3
- Lead with the most interesting detail, not the setup
- Use a question, bold statement, or emotional beat
- Cut everything before the hook

### If Specificity < 3
- Add one concrete detail: name, place, object, quote
- Replace "beautiful" with what made it beautiful
- Replace "emotional" with what the emotion looked like

### If Value Density < 3
- Identify the one thing a reader should leave with
- Cut tangents that don't serve that takeaway
- Add a practical tip or insight

### If Emotional Resonance < 3
- Find the human moment in the story
- Name the emotion, don't just imply it
- End with feeling, not information

## Channel-Specific Gates

### Instagram
- [ ] Hook fits on first line without truncation
- [ ] 50-150 words
- [ ] 8-15 hashtags, mix of broad + local
- [ ] Soft CTA (question or invitation, not demand)
- [ ] Emoji count ≤ 3

### Blog
- [ ] Title includes location and venue
- [ ] 500-1200 words
- [ ] Scannable structure (H2s, bullets, short paragraphs)
- [ ] SEO: location in first 100 words
- [ ] One clear takeaway or emotion at the end

### Newsletter
- [ ] Subject line under 50 characters
- [ ] Opening feels personal, not broadcast
- [ ] One main story + 2-3 quick links
- [ ] Soft CTA, no sales pressure
- [ ] Sign-off with Jonah's name

---

## Auto-Rewrite Triggers

The Content Agent should auto-rewrite if:
- Any dimension scores 1-2
- Average score < 3.5
- Contains banned phrases (see below)

**Banned phrases (flag for rewrite):**
- "timeless elegance"
- "capturing memories"
- "your special day"
- "unforgettable moments"
- "passionate about"
- "stunning visuals"
- "exquisite details"
- "once-in-a-lifetime"

---

## Human Review Queue

Flag for Jonah's review if:
- Content references a specific client (privacy check)
- Content mentions a vendor partnership (accuracy check)
- Score is borderline (3.0-3.5 average)
- Topic is sensitive (pricing, competition, negative experience)

**Never auto-publish:** Client-specific content without review.
