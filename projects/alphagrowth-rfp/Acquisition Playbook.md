# **1. Growth Principles**

### **1.1 The Growth Funnel**

**Awareness → Acquisition → Activation → Retention → Referral → Revenue**

But for DeFi, I want to modify this slightly because **economic activity is itself part of activation**:

**Awareness → Acquisition → Onboarding → First meaningful action → Repeat activity → Referral → Economic value**

### **1.2 Growth Loops vs. Funnels**

This may be one of the most important concepts in the entire playbook.

A **funnel** looks like:

Marketing → User → Transaction

A **growth loop** looks like:

User → Activity → Value → Invitation/visibility → New User → Activity → Value…

The second can become self-reinforcing.

### **1.3 Acquisition ≠ Activation**

Someone downloading a wallet isn’t necessarily a user.
Someone connecting a wallet isn’t necessarily a user.
Someone receiving an airdrop isn’t necessarily a user.

We should define **activation** as the first action demonstrating genuine product value.

For a DeFi platform that might be:
- first swap
- first deposit
- first liquidity position
- first borrow
- first payment
- first recurring transaction

This distinction will become extremely important when we examine airdrops and quests.

### **1.4 Incentives**

We’ll create a taxonomy:

**Financial**
- cash
- free stock
- token
- fee rebate
- yield
- liquidity rewards

**Non-financial**
- access
- status
- NFTs
- points
- badges
- reputation
- governance rights

And then ask:

**What behavior does the incentive purchase?**

That’s a much better question than simply asking whether a project “used incentives.”

### **1.5 Education**
We’ll distinguish:

**Passive education**
Articles, videos, newsletters

**Contextual education**
Explain something immediately when the user encounters it

**Interactive education**
Quizzes, simulations

**Experiential education**
“Do the thing and learn while doing it”

That last category is particularly relevant to **quests**.

### **1.6 Gamification**
We should be careful here because gamification isn’t simply “points.”

We’ll investigate:
- progress bars
- levels
- badges
- streaks
- milestones
- challenges
- leaderboards
- collectibles
- unlockable features
- scarcity
- status

And ask whether the game mechanic is actually reinforcing **useful behavior**.

### **1.7 Referral Mechanics**
There are several fundamentally different referral models:

**Simple referral**
Invite friend → $10

**Dual-sided referral**
Invite friend → both receive reward

**Progressive referral**
1 referral → $10  
5 → $100  
20 → $500

**Affiliate**
Referred user’s activity → recurring revenue

**Network referral**
Your network’s activity → your reward

The distinction will matter enormously when we look at DeFi.

### **1.8 Retention**
Acquisition can be bought.

**Retention has to be earned.**

We’ll examine what actually causes users to return:
- financial opportunity
- utility
- habit
- community
- content
- portfolio monitoring
- rewards
- governance
- social status
- recurring transactions

### **1.9 Sustainable Growth**

This is where I’d connect the playbook to your broader blockchain research.

We’ll eventually ask:
**Does the user generate more economic value for the protocol than the protocol spends acquiring and retaining the user?**

Conceptually:

**User Lifetime Value (LTV)**
versus
**Customer Acquisition Cost (CAC)**

But for DeFi we should expand this to:

**Protocol economic value generated**
versus
**Incentive + infrastructure + acquisition cost**

And distinguish **real economic activity** from activity that exists primarily because the protocol is paying people to generate it.

## **And one principle I’d put right at the top**

### **The best growth hack reduces the cost of doing something people already want to do.**

Robinhood didn’t have to convince millions of people that investing was desirable.
It dramatically reduced the friction and cost of doing it. That’s potentially very relevant to your Ethereum → Cardano idea.

Instead of asking:
**“How do we incentivize Ethereum users to learn Cardano?”**

we might ultimately ask:
**“How do we remove enough friction that an Ethereum user can get the benefit of Cardano DeFi without first becoming a Cardano expert?”**

Then **education, quests, incentives and referrals become accelerators**, rather than compensation for an unpleasant onboarding process.

That’s the Growth Principles foundation I’d use
