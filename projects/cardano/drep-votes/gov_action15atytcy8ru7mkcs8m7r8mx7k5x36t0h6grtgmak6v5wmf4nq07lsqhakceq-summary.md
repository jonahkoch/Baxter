# Vote Summary (IPFS-ready)

**Vote: YES** on raising the Net Change Limit from 350M to 500M ADA (Epochs 613–713).

**Why:** The original 350M NCL was set when ADA traded at ~$0.30 (~$105M USD equivalent). At today's ~$0.16, that same limit equals only ~$56M — a 47% drop in real Treasury capacity that was never intended by the DReps who agreed it. Projects budget in USD; the NCL caps ADA. When ADA drops, the same scope requires more ADA. This is an accidental tightening, not fiscal discipline.

**500M ADA at $0.16 = ~$80M USD.** This partially restores lost purchasing power without fully compensating for the price decline. A fully adjusted NCL would require ~650M. 500M is a measured middle ground.

**Addressing concerns:**
- The NCL remains a maximum, not a target. Every withdrawal still needs 67% DRep approval individually.
- I share concerns about slippery slopes. Future NCLs should include price-adjustment methodology, not round numbers.
- If ADA recovers, future ceilings should be evaluated for downward adjustment. Constraints must work both ways.

**I am a conservative Treasury steward. I believe constraints should be intentional, not accidental. Vote YES.**
