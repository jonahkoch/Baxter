# Purpose: kochfoto-agents

## Motivation

This skill was created to provide a structured, resumable workflow for building Kochfoto's
three AI agents incrementally. Photography business operations involve repetitive, 
knowledge-intensive tasks that benefit from agent automation, but building all three at once
is overwhelming and error-prone.

## Wiki Patterns Addressed

- **Incremental project work** — Large projects decomposed into discrete phases with clear entry points
- **Session continuity** — Each session can resume from where the last left off via action-plan.md
- **Context loading discipline** — Forces reading of project state before acting
