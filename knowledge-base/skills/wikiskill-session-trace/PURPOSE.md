# Purpose: wikiskill-session-trace

## Motivation

Without structured session traces, the Wiki Maintainer has no raw material to extract patterns from.
Casual chat and task-oriented work are mixed in the same conversation. This skill provides the
discipline to capture only significant sessions in a consistent format.

## Wiki Patterns Addressed

- **Raw material for pattern extraction** — Traces are the input to the Wiki Maintainer
- **Session type discrimination** — Distinguishes casual from task-oriented work
- **Honest failure logging** — Encourages documenting what went wrong, not just what worked
